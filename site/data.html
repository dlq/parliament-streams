Data and method

An open source project documenting legislatures, official broadcasts and programme data.

Data and methodContributeCode

  1. Research inventory

    Bodies and chambers, with evidence about legislative authority and research scope. A body record does not establish an available broadcast.

  2. Viewing-source catalogue

    Official viewing sources linked to those institutions. A source can be an external page, an archive or an in-page player.

  3. Checks and review

    Technical access, identity, feed mapping and reuse rights are separate findings. Automation proposes changes for human review; it does not automatically admit sources.

  4. Generated products

    Reviewed records generate these pages and files. Programme timestamps are stored in UTC and displayed in the viewer’s local timezone.

Public files

Inventory and catalogue changes are reviewed and committed. Schedules and exports refresh every six hours.

Coverage and reuse

Guide coverage is partial. “Automated schedules” counts sources connected to an implemented parser, not populated guides. Event listings and XMLTV coverage are separate; XMLTV requires a reviewed exact feed mapping and complete times. Collection errors are different from a confirmed empty listing window.

Project code licensing is separate from broadcast and source-data rights. Check each source’s conditions; no blanket licence is asserted for third-party material.
