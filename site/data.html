Methods

Researchers reconcile official institutions and source ownership, then record identity, technical access, accessibility and rights as separate findings. Automated checks propose changes for human review; dated reports preserve what was actually checked.

  1. Research inventory

    Bodies and chambers, with evidence about legislative authority and research scope. A body record does not establish an available broadcast.

    catalogue-scope.md

  2. Viewing-source catalogue

    Official viewing sources linked to those institutions. A source can be an external page, an archive or an in-page player.

    catalogue-maintenance.md

  3. Checks and review

    Technical access, identity, feed mapping and reuse rights are separate findings. Automation proposes changes for human review; it does not automatically admit sources.

    data-validation.md

  4. Generated products

    Reviewed records generate these pages and files. Programme timestamps are stored in UTC and displayed in the viewer’s local timezone.

    github-actions.md

Collectors distinguish empty listings from failed requests and mark retained data as stale. Source timezones are normalized to UTC; the website displays your local time. A meeting calendar is not automatically a television programme guide.

Scope and method

Our current research covers 71 country groups from the EIU Democracy Index 2024 baseline, including first-level and autonomous special-status legislatures. Chambers and distinct legislative organs are listed within their institutions where applicable. This is a working inventory; completeness and viewing-service validation remain separate.

Legislatures
Legislative authority must be supported by evidence. Ordinary municipal and advisory bodies are excluded; unresolved authority cases stay marked. A viewing source is not required for the inventory.
Viewing-source catalogue
Requires an identified official source of legislative video or audio, live or recorded. Unusable or research-only viewing routes stay outside the catalogue. Sources beyond the inventory’s research priorities can qualify; embedding and reuse are reviewed separately.
Schedule
Official calendars remain useful links even without a collector. Automated listings need structured source data with explicit dates and times; missing times are not invented. XMLTV also needs a reviewed exact feed mapping and credible programme start and end times.

Institution names follow the source records; research notes are available in English.

No documented viewing source is a research gap; it does not establish that the institution has no broadcasts.

Coverage and reuse

Guide coverage is partial. “Automated schedules” counts sources connected to an implemented parser, not populated guides. Event listings and XMLTV coverage are separate; XMLTV requires a reviewed exact feed mapping and complete times. Collection errors are different from a confirmed empty listing window.

Project code licensing is separate from broadcast and source-data rights. Check each source’s conditions; no blanket licence is asserted for third-party material.

Colophon

Darcy Quesnel · dlq/parliament-streams

A static HTML, CSS and JavaScript site, built from maintained data with Python tools and published through GitHub Actions and GitHub Pages. D3 draws the map; HLS.js supports compatible video playback. Headings use Georgia with system-font fallbacks.

No accounts, project analytics or stream proxy. Interface language is stored locally in your browser. Choosing playback can contact the official broadcaster or provider, whose privacy terms also apply.

Project code uses the BSD 3-Clause licence. Images, flags, maps, icons and bundled libraries retain their own credits and licences. Broadcast and source-data rights are separate.
